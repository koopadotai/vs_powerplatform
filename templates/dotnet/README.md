# .NET Templates

Reusable starter projects for .NET 10.

| Template | Purpose |
|---|---|
| `api-starter/` | ASP.NET Core Minimal API with auth, OpenAPI, observability |
| `function-starter/` | Azure Functions isolated worker model |
| `ai-middleware-starter/` | AI orchestration service with Anthropic SDK |
| `mcp-server-starter/` | Model Context Protocol server |
| `dataverse-plugin-starter/` | Dataverse plugin (server-side custom logic) |

Standards: [`memory/dotnet-api-standards.md`](../../memory/dotnet-api-standards.md).

> Phase 1 ships with the directory. Full templates are added in Phase 2.
