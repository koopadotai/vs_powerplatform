# UI/UX Templates

Reusable layouts and theme systems for Power Apps.

| Template | Purpose |
|---|---|
| `layouts/phone/` | Mobile-first layouts (header + content + nav) |
| `layouts/tablet/` | Tablet split-view layouts |
| `layouts/dashboard/` | KPI dashboard layouts |
| `themes/` | Color/spacing/typography systems (corporate, modern, dark) |
| `components/` | Reusable Canvas App components (buttons, cards, gallery rows) |

> Phase 1 ships with the directory. Templates are added in Phase 2.
